# 学习契约

## 根本目标

能独立读懂本仓库 Go2 速度跟踪的全部 TB 标量（`md/TB指标清单.md`）。对**每一条**都能按下面 6 点讲清，并对照代码验收：

1. 中文定义  
2. 相关代码（在哪、算什么）  
3. 升高/降低代表什么、这项起什么作用  
4. 什么会让它升或降，代码哪里体现  
5. 会连带影响哪些别的曲线  
6. 太高/太低会有什么后果  

（同时保留原工程目标：训练侧架构、纯 RL / mimic、部署链路——TB 读懂是当前主线。）
